# 01. 보드 결선

> 회로도 `hardware/stm32h563_core_v1.pdf` (STM32H563_CORE Rev 1, 3 시트) 에서 읽은 값이다.
> 회로도만으로 확정하지 못한 것은 ⚠️ 로 표시했다.

---

## 1. MCU

| 항목 | 값 |
|---|---|
| 부품 | **STM32H563RIT6** (U1) — LQFP64, Flash 2 MB, SRAM 640 KB |
| 코어 | Cortex-M33 + FPU (single) |
| 전원 | VDD ×4, VDDA (+3.3VA), VCAP ×2 (2.2 µF), VBAT ← `BAT` |

---

## 2. 클럭

| 소스 | 부품 | 핀 | 비고 |
|---|---|---|---|
| HSE | Y2 25 MHz (3225, 20 pF 부하) | PH0 / PH1 | R11 100Ω 직렬 |
| LSE | Y3 32.768 kHz (3215, 18 pF 부하) | PC14 / PC15 | R13·R14 0Ω |

참고 프로젝트(`stm32h5-w6300`)도 HSE 25 MHz 라서 `SystemClock_Config()` 를 그대로 쓴다.

---

## 3. LED (시트 3)

| 부품 | 연결 | 저항 | 용도 |
|---|---|---|---|
| D1 | +5V | R17 33K | 전원 표시 |
| D10 | +3.3V | R20 15K | 전원 표시 |
| **D11** | **PC13 (`PC13_LED`)** | R32 15K | 사용자 LED → `_DEF_LED1` |

⚠️ 회로도상 D11 은 +3.3V 쪽에 애노드가 있고 R32 를 거쳐 `PC13_LED` 로 내려오는 형태로 읽힌다 →
**active low** 로 구현했다. 참고 프로젝트의 PC13 LED 와 같은 극성이다. 실물로 확인할 것.

PC13 은 백업 도메인의 핀이라 구동 능력이 약하다(데이터시트상 sink 3 mA 제한).
LED 저항이 15K 라 전류는 0.1 mA 수준이어서 문제없다.

---

## 4. 디버그 커넥터 J1 (12505WS-06, 6핀)

| 핀 | 신호 | MCU |
|---|---|---|
| 1 | +3.3V | |
| 2 | SWDIO | PA13 |
| 3 | SWCLK | PA14 |
| 4 | GND | |
| 5 | U1_TXD | PB15 |
| 6 | U1_RXD | PB14 |

⚠️ U1_TXD / U1_RXD 의 핀 번호는 J1 의 배치를 회로도에서 읽은 값이다. 방향(보드 기준인지 어댑터 기준인지)은
UART 를 붙이는 단계에서 데이터시트 AF 표와 실측으로 확정한다.

`hardware/hg-swd-prog_V1.pdf` 가 이 커넥터에 물리는 프로그래머다.

---

## 5. 리셋 / BOOT0

| | 부품 | 동작 |
|---|---|---|
| RESET | S2 | NRST 를 GND 로. C23 100 nF, D14 ESD |
| BOOT0 | S3 | 누르면 R1 4.7K 로 +3.3V. 평소 R12 10K 로 GND → 유저 플래시 부팅 |

---

## 6. QSPI 플래시 U3 (W25Q256JV, 32 MB)

| 신호 | MCU |
|---|---|
| CS | PB10 (R7 10K 풀업) |
| CLK | PA3 |
| D0 | PC3 |
| D1 | PB0 |
| D2 | PC2 |
| D3 | PA1 |

데이터 라인마다 27Ω 직렬 저항 (R2~R6).

---

## 7. USB / 전원 (시트 3)

| | 내용 |
|---|---|
| USB-C J7 | DM/DP → PA11 / PA12. CC1/CC2 5.1K 풀다운 (디바이스). D5 SR05 ESD |
| 5V → 3.3V | U18 SY8205FC 벅, 피드백 R29 22.1K / R30 100K |
| VBAT | J6 커넥터 → `BAT` (C24 10 µF) |

---

| J4 | PB12, PB13, U1_RXD, U1_TXD, PC0, PC1, PC4~PC12, PC13_LED, PD2, NRST, BOOT0, +5V, +3.3V |
