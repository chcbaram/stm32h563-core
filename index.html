STM32H563 Core

브라우저에서 보드에 직접 연결해 펌웨어와 부트로더를 업데이트한다. GitHub

Chrome 또는 Edge 가 필요하다 (WebHID · Web Serial · WebUSB). 보드의 USB-C 를 연결한다. 펌웨어가 돌고 있어도 업데이트할 수 있다.

보드 연결

연결되지 않음

HID 는 터미널이 CDC 를 CLI 로 쓰고 있어도 된다. CDC 는 다른 프로그램(터미널)이 그 포트를 열고 있으면 열 수 없다.

보드가 부트로더로 바뀌었다. 처음 한 번 목록에서 STM32H5-BOOT 를 골라 줄 것

부트로더 업데이트 (ROM DFU)

  1. 보드의 BOOT0 버튼(S3) 을 누른 채 리셋 버튼(S2) 을 눌렀다 뗀다. 그다음 BOOT0 을 뗀다
  2. STM32 의 시스템 부트로더(ROM)가 USB DFU 장치(0483:DF11)로 나타난다
  3. 아래 버튼을 누르고 목록에서 DFU in FS Mode 를 고른다

Windows 에서는 ROM DFU 장치에 WinUSB 드라이버가 붙어 있어야 WebUSB 로 열 수 있다 (ST 드라이버가 깔려 있으면 Zadig 등으로 바꾼다). 다 쓰면 BOOT0 을 뗀 상태에서 리셋(S2) 을 눌러 새 부트로더로 실행한다 (ROM DFU 에서 바로 실행시키면 이 칩은 락업에 빠진다). 앱은 그대로 남는다.
